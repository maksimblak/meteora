# 16 — Метрики GMGN через официальное OpenAPI

**Требования:** G18, G20
**Зависит от:** 12
**Зона:** `src/gmgn/` · `src/worker/runtime.py` · `tests/gmgn/` · `docker-compose.yml` · `.env.example`
**Волна:** 10
**Ревью:** да — внешний источник риска, секретный ключ и fail-closed для live
**Модель:** сильная

## Что должно заработать

Бот получает insiders, bundling, phishing, top-10 и долю девелопера по каждому кандидату из официального GMGN OpenAPI по ключу пользователя — без браузера и без Cloudflare. С ключом метрики GMGN свежие, пороги гайда работают, и автоматический live перестаёт упираться в `GMGN_UNAVAILABLE`. Без ключа всё работает как сейчас.

## Критерии приёмки

- [ ] провайдер официального OpenAPI в `src/gmgn/` (httpx, без новых зависимостей) читает `GET /v1/token/info` и `GET /v1/token/security` для `sol`; базовый адрес и способ передачи ключа взяты из официального источника (CLI/документация GMGNAI/gmgn-skills) и записаны в коде со ссылкой; адрес настраивается переменной
- [ ] отдаёт тот же `EnhancedTokenSignals` и те же имена evidence, что браузерный путь T12: insiders ← `top_rat_trader_percentage`, bundling ← `top_bundler_trader_percentage`, phishing ← `top_entrapment_trader_percentage`, top-10, доля девелопера; пороги `guide-v1`, `GMGN_UNAVAILABLE`, правило LIVE и панель не меняются
- [ ] ключ — `GMGN_API_KEY` (и `_FILE`, если так устроены другие секреты проекта): не попадает в логи, исключения, DTO, decision record, `config/effective`; в `.env.example` — пустое имя с комментарием, где создать ключ
- [ ] limiter ниже тарифа (по умолчанию Free: 5 запросов/с с учётом веса), 429 уважает `X-RateLimit-Reset`/`reset_at` и не продлевает бан повторами; 401/403 и `PLAN_UPGRADE_REQUIRED` → «недоступно» с причиной, без повторов; только IPv4; кэш на токен, запросы только для кандидатов
- [ ] выбор источника в worker: есть ключ → OpenAPI; нет ключа, есть `GMGN_URL` → браузерный сервис; нет ничего → как сейчас; тест на каждый вариант
- [ ] разбор ответов покрыт тестами на фикстурах в формате официального ответа; изменение формата даёт degradation, а не падение; обычные тесты не ходят в сеть; ручная smoke-команда для живой проверки по ключу
- [ ] total fees: если официальный ответ даёт значение — передаётся в `total_fees_sol`, иначе флаг `TOTAL_FEES_UNAVAILABLE` как раньше (D03)
