# 0013. Метрики GMGN без ключа — через браузер-посредник на хосте

## Контекст

Метрики GMGN (снайперы, инсайдеры, бандлинг, статус девелопера, total fees, объём токена, ATH) нужны отбору и выходам по гайду. Официальный OpenAPI (ADR 0002, G20) выдаёт бесплатный ключ только при балансе от $100 на аккаунте GMGN — пользователь отказался класть деньги. Headless-браузер в Docker (T12) Cloudflare блокирует (403). Разведка 2026-10-24 показала: изнутри открытой вкладки gmgn.ai в обычном видимом Chromium внутренние адреса сайта отвечают и отдают всё нужное; снаружи браузера и API, и сама страница — 403.

## Решение

- Сервис `gmgn` получает режим bridge: он запускается на хосте одной командой, открывает видимое окно официального Playwright Chromium с постоянным профилем вне репозитория и держит одну долгоживущую вкладку gmgn.ai. Данные — `fetch` найденных адресов из контекста этой вкладки, нормализованные в контракт `gmgn-signals.v2`. Worker в Docker ходит к нему по `GMGN_URL` с общим токеном.
- Куки и сессия остаются в профиле окна. Вход в аккаунт не нужен (данные идут и без него); пользователь может войти сам, если захочет работать в своей сессии.
- Никаких stealth-плагинов, подмены UA и отпечатков, решателей капч. После 429, 403 или challenge — пауза, которую соблюдают и загрузки из очереди; обхода нет.
- Ключ OpenAPI, если появится, по-прежнему в приоритете.

## Почему

- **Вынос cookie в бот** (запросы из Python или Docker с куками браузера): пропуск Cloudflare привязан к браузеру; заставить его работать можно только подделкой TLS-отпечатка и браузера — это обход антибот-защиты. Отвергнуто. Проверить запрос с куками вне браузера не дал фильтр безопасности Claude Code; пользователю предложена ручная проверка через Copy as cURL.
- **Автоматический вход в аккаунт:** вход GMGN — подпись кошелька, Telegram или Google; бот должен был бы хранить ключ или сессию, а при бане под удар попадает торговый кошелёк. Отвергнуто.
- **Jupiter Tokens API + RugCheck** (бесплатно, официально): объём, органичность, доля девелопера, топ-держатели — но нет снайперов, инсайдеров, бандлинга и ATH токена. Предложено как основа; пользователь выбрал реверс GMGN. Остаётся запасным вариантом.
- **Депозит $100 ради ключа:** отклонён пользователем.

## Последствия

- Работает, только пока окно посредника открыто и компьютер не спит; на сервере без рабочего стола не запускается.
- Против правил GMGN: при входе в аккаунт риск бана аккаунта с привязанным торговым кошельком; без входа — риск блокировки IP.
- Внутренний API сайта не документирован и меняется вместе с сайтом (`app_ver`); поломка видна как `GMGN_UNAVAILABLE` с причиной, бот продолжает работу без GMGN.
- Первый запрос свежей сессии иногда получает 429 — посредник встаёт на паузу 15 минут.
- LIVE без свежих данных GMGN закрыт, как и раньше (ADR 0004): если посредник недоступен, автоматический режим ждёт.
